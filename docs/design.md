# 拾知：知识标本室

对象：希望借助 AI 积累知识的个人学习者。主要任务：把用户提供的字幕文件、视频、笔记与追问沉淀为能持续复习的本地 Markdown；Glean 独立提供新建、编辑、阅读与仓库管理。

设计参考：Anthropic frontend-design（https://skills.sh/anthropics/skills/frontend-design）。

色彩：雾白 #f5f7f5、深松绿 #203d32、叶绿 #648676、浅苔 #e8eee7、墨灰 #293830、暖金 #b99659。
字体：中文标题使用系统宋体，操作与正文使用系统无衬线；数字用衬线大字，与笔记阅读的书卷感呼应。
布局：窄侧栏固定锚点；首页左侧引言与统计，右侧知识植物；底部展示最近半年学习足迹。在 1000 × 700 及常规桌面窗口中适配高度，无需滚动即可看到全貌；窄屏保留自然滚动。

```
┌──────┬──────────────────────────────┐
│ 拾知 │ 工作台                     日期 │
│      │                              │
│ 生长 │ 让好奇心，     知识植物        │
│ 笔记 │ 长成自己的森林。  · · ·       │
│ 设置 │ 真实统计       ╱╲             │
│      │ 新建入口       │              │
│      ├──────────────────────────────┤
│ 本地 │ 最近半年学习足迹               │
└──────┴──────────────────────────────┘
```

植物由 SVG 程序绘制，避免通用卡片堆砌。空库只显示种子，累计笔记构成叶片，双链增加连接线；不伪造学习数据。主动态集中在植物轻微呼吸，遵守减少动态效果偏好。细线、留白与不对称构图承担视觉层次。没有额外社区、任务清单、课程市场或博客输出功能。

「我的笔记」顶部提供手动新建与 AI 生成两个入口，仓库卡片持续显示真实保存位置；下方提供筛选、摘要搜索与 Markdown 导入。笔记详情支持标题/正文编辑、文件定位和版本恢复。生成采用完整素材的一次模型调用，以简洁复习笔记为目标；文件保存失败不会报告生成成功。
